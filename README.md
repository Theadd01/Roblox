# WW3 (Roblox)

Scripts du jeu, au format Rojo (`default.project.json`, dossier `src/`).

- Refonte v2 (combat, généraux, recherche, Conseil mondial) : voir [docs/REFONTE_V2.md](docs/REFONTE_V2.md).
- Tests hors de Studio : `lune run tools/lune/run_tests.luau`.
- Réinjecter `src/` dans une place existante :
  `lune run tools/lune/patch_place.luau <entrée.rbxl> <sortie.rbxl>`.
